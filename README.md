## Archivos que debes sustituir

Sustituye directamente en la raíz del repositorio:

- `index.html`
- `styles.css`
- `assets/garden.svg`

No borres ni sustituyas los demás archivos (`main.js`, `config.js`, páginas legales, logotipo, favicon, etc.).

- Hojas conectadas correctamente a sus tallos.
